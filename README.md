A program that writes one line — a roast of the gadget used every day — to `/output/entry.txt`: *"My fitness tracker gave me a badge for walking to the fridge and then suggested I rest, as if opening it were a workout."* The tracker treats a trip to the fridge as an athletic achievement worthy of a badge and a recovery period.

## Run it

```sh
node main.ts
```
